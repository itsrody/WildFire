      Dynamic site rules
      
    
      Per-site block and allow rules override static filters for a resource type. Set them from the toolbar popup; navigation rules are never applied.
      
    
        
  
        

  
        
    
        My rules
        
    
        One rule per line: source destination type action. Use * for any source, destination, or type; actions are block, noop, and allow. Local rules override global rules, and destination rules override type rules. Popup rules are temporary until persisted; rules saved here are persistent.
        
    
    
        
    
        
    
        
      
      
      
    
        
  
        

  
        
    
        CSP reports
        
    
        CSP violation reports are development telemetry and can be used as a fingerprinting signal. WildFire removes report directives from CSP headers and cancels legacy CSP report requests. Enforcement directives stay intact.
        
    
    
        Comma-separated report endpoint hosts that may still receive reports.
        
    
        
      
      
      
    
        
  
        

  
        
    
        CNAME uncloaking
        
    
        WildFire asks Firefox DNS for the canonical host of a request and uses cached aliases to match domain rules, $domain=, third-party checks, and site counters. Resolution is local and only the first request to a new alias may pass before its cached name is known.
        
    
  
        

  
        
    
        Suggested lists
        
    
        Shortcuts to well-known community lists. Adding one fetches its URL once but leaves it disabled; choose Enable to apply its rules.
        
    
          
  
          

  
          
    
          Filter lists
          
    
          The preshipped WildFire list, the preshipped uAssets CDN list, and any list you add are fetched once and then revalidated on the list's own !Expires interval. User-added lists start disabled; enable one to apply its rules. Auto can be turned off per list. WildFire stores the exact text it applies.
          
    
            
    
            
      
      
      
    
            
  
            

  
            
    
            Local assets
            
    
            Inspect the WildFire-owned redirect, CSP, rewrite, and scriptlet registries. Values are local data only; filter text can select an alias but cannot supply its own body, header, URL, or script.
