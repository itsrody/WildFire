WildFire options

Minimal uBO-style blocking for Firefox 153+ (ESR).

Custom filters

One rule per line. Supports ||domain^, @@ exceptions, $domain=, $script, $third-party, curated $csp= headers, curated $rewrite= bodies, ##selector hiding, and curated ##+js() scriptlets.

Paused sites

Blocking is skipped on these hosts.

    Remote filter lists

    Nothing is bundled or fetched automatically. Add an http(s) URL, fetch it explicitly, then enable it. WildFire stores the exact text it applies.
