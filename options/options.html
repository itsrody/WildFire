WildFire options

Minimal uBO-style blocking for Firefox 153+ (ESR).

Custom filters

One rule per line. Supports ||domain^, @@ exceptions, $domain=, $script, $third-party, curated $csp= headers, curated $rewrite= bodies, ##selector hiding, and curated ##+js() scriptlets.

Paused sites

Blocking is skipped on these hosts.

    CSP reports

    CSP violation reports are development telemetry and can be used as a fingerprinting signal. WildFire removes report directives from CSP headers and cancels legacy CSP report requests. Enforcement directives stay intact.

    Comma-separated report endpoint hosts that may still receive reports.

    Suggested lists

    Shortcuts to well-known community lists. Adding one only registers its URL — nothing is downloaded or enabled until you choose Fetch, then Enable.

      Remote filter lists

      No list is added or fetched automatically. Add an http(s) URL, fetch it explicitly, then enable it. WildFire stores the exact text it applies.
